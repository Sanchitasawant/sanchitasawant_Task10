# Laundry Service Landing Page

This is a simple laundry service landing page made with HTML and CSS. I created a navigation bar, a hero section, a call-to-action button, and a small animation on the laundry image. The layout also adjusts for smaller screens.

## Files

- `index.html` – page structure and content
- `style.css` – page styling, responsive layout, and image animation

## Run the project

1. Open the project folder.
2. Open `index.html` in a browser.
3. Resize the browser window to check the responsive layout.
4. Move the cursor over the booking button to see the hover effect.

## Animation

The image on the right moves slightly, rotates, and changes size during the animation. It repeats continuously using CSS `@keyframes`.
